基本操作

操作動作
SELECT + START を1秒長押しメニューを開く
PWR 短押しメニューを開く
PWR + UP / DOWN音量を調整
PWR + AAボタンの連射（ターボ）をON/OFF
PWR + BBボタンの連射（ターボ）をON/OFF
PWR + STARTセーブして電源OFF
PWR を3秒長押しセーブして電源OFF
起動時に START + PWR を押しっぱなし設定を初期化（電池が必要）

ターボをONにすると、その場でコイン音が鳴って通知されます。ターボ中の A/Bの単押しはゲーム側には渡りません。
電源ボタン（PWR）は電池の電圧を読んで検知するため、USB給電のみでは反応しません。 開発・操作時は電池を入れておいてください。

メニュー画面

メニューを開くとヘッダに電池アイコンと残り分数が表示されます。 項目は次のとおりです。

項目内容
VOLUME音量を調整（左右キー）
BRIGHTNESS画面の明るさを調整（左右キー）
GAMEカートリッジ（ROM）を切り替える
BLE MODEBLEでのROM転送モードに入る（詳細は下記）
MANUALこのマニュアルへのリンクのQRコードを表示
RESETゲームをリセット（セーブデータも削除）
POWER OFFセーブして電源OFF（USB接続中は非表示）

セーブについて

メニューを開くたびに自動でセーブされます。セーブスロットはゲームごとに1つです。

BLEモードでのROM転送

メニューから BLE MODE を選ぶと、本体は NES-S3 という名前でBLEアドバタイズする転送モードに再起動します。 このモードでは本体に入っているROMの一覧表示・アップロード・削除・起動ゲームの 選択ができます。Bボタンを1秒長押しするとゲームに戻ります。

クライアントは次の2種類があります。

1. WebBLE版（ブラウザから）

このサイトの webble.html を Chrome または Edge で開いて Connect を押してください。Web Bluetooth に対応したブラウザが必要です。 このページ自体が https で配信されているので、そのまま webble.html を直接開いて使えます。

2. CLI版（コマンドラインから）

リポジトリ内の scripts/blerom.py を使います。事前に bleak のインストールが必要です。 

pip install bleak

コマンド一覧:

blerom.py list                 本体上のファイル一覧と空き容量を表示
blerom.py put <file.nes>       ROMをアップロード（同名は上書き）
blerom.py del <name.nes>       ファイルを削除
blerom.py boot <name.nes>      そのカートリッジを選んで再起動
blerom.py exit                 BLEモードを終了（現在のゲームに戻って再起動）

ROMについて

oss_roms/ にはオープンソースのROMが同梱されています （Nova the Squirrel、240p Test Suite、ベンチマーク用の bench.nes）。

自分で用意したROMを使う場合は、次のいずれかの方法があります。

  • my_roms/ に .nes ファイルを置いてビルド・書き込みする
  • 本体を BLE MODE にして、上記の WebBLE または CLI からROMを転送する

English Summary

esp-game1 is the NES emulator firmware for masuidrive's custom ESP32-S3 portable game console. Hold SELECT+START for 1 second (or press PWR) to open the on-screen menu. Its header shows a battery icon with estimated minutes remaining. Menu items: VOLUME, BRIGHTNESS, GAME (cartridge picker), BLE MODE, MANUAL (QR code to this page), RESET, and POWER OFF (hidden while USB is connected). The game auto-saves whenever the menu opens, one save slot per game.

PWR+UP/DOWN adjusts volume, PWR+A / PWR+B toggles turbo (auto-fire) for that button, PWR+START or a 3-second PWR hold saves and powers off. Holding START+PWR at boot resets settings to defaults (a battery must be installed - the power button is sensed from battery voltage and doesn't respond on USB power alone).

BLE MODE reboots the device into a transfer mode that advertises as NES-S3, letting you list, upload, delete, and select ROMs over Bluetooth Low Energy. Hold B for 1 second to return to the game. Two clients are available: the browser-based webble.html (Web Bluetooth, works directly from this site in Chrome/Edge), or the CLI scripts/blerom.py (pip install bleak) with list / put / del / boot / exit commands.

Open-source ROMs (Nova the Squirrel, 240p Test Suite, a bench ROM) ship in oss_roms/. Add your own by placing .nes files in my_roms/ before building, or by transferring them over BLE.
