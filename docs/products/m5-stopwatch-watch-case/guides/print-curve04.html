湾曲ケース v4 の試作と造形ガイド

確認日：2026年10月12日。対象：design_v4。寸法単位：mm。

このガイドは、SMALL 系の Apple Watch バンドを受ける試作ケースについて、家庭での嵌合確認、JLC3DP の材質選び、寸法違いの注文、試験結果の記録方法をまとめたものです。最初の試作は、6条件を切り離さず比較できる縦積み一体ブロック1個です。まず Adventurer 3 と PETG で形状を絞り、JLC3DP の最終材でも同じ実形状で再確認する方法を推奨します。個別6種類のファイルはバックアップとして残します。日常使用を検討する材質の第一候補は MJF PA12-HP、形状確認用には SLA レジンも選択肢です。

このモデルは嵌合試作です。CAD の形状検査に合格しても、実物バンドとの嵌合、ラッチ保持、解除、摩耗、耐荷重は保証されません。 現版は元の BANDBASE2 の湾曲を維持し、Pk11 の公開バンドアダプター v3 を参考に受け断面を構成した版です。公開モデルの存在や CC0 ライセンスは、この改変版と使用バンドの適合・耐久性の証明にはなりません。Apple の公式 CAD 曲線をそのまま再現したものではなく、寸法補正だけでは断面形状の不一致を解消できない場合があります。

元ケース：kawacci/m5-stopwatch-watch-case。受けの参考：Pk11 Apple Watch band adapter for iPod nano 6。正確な採用版・加工範囲は同梱の出典・CAD検証資料を参照してください。旧 design の形状・寸法・試験結果とは混ぜません。

v4 で変更した本体と試験片の違い

本体の製造用データは export/m5_small_band_curve_v4.step と export/m5_small_band_curve_v4.stl です。FDMの側面置き用は export/m5_small_band_curve_v4_print_axisZ.stl を使います。これらは同じ本体の形式・姿勢違いなので二重に印刷しません。

v4はケース側の肩と受け外形を作り直した版です。単純な直方体の受けを追加した形状として扱わず、元の腕側の湾曲と装着部を保った連続したケース側支持形状として確認してください。

  • 旧版の外側C0.30面取りを置き換え、受けを含む外形の上面・前面・側面・下面の外周に実際のR1.00mmの丸みを設けています。溝や穴を加工する前の外形に対する角丸処理です。R1.00は丸み半径で、入口のC0.15面取りとは別の処理です。
  • 左右スライド入口の4本の円弧には、C0.15mmの導入面取りがあります。元の組立座標で両端の絶対X座標17.10〜17.25mmだけに限定し、中央の係止部には届きません。
  • 中央の基準H3.50、P5.50、溝奥行3.50、口高さ2.50、開口短辺2.25、および中央の受け断面・ラッチ開口は変更していません。
  • 肩から受けへ幅が移る部分はG2接続の幅変化曲線を用いています。これはその移行曲線の設計条件で、部品全体の全エッジがG2連続であるという意味ではありません。元のケースの丸い印象を参考にしていますが、元外形との完全一致を保証するものではありません。 中段から下側の側面には薄い接線・面の切り替わり線が残ります。上側の広い接続部の連続した丸みと、部品全体が完全に無継ぎ目であることは区別してください。

同梱の一体ブロックと個別試験片は変更していません。旧試験片には有効なC0.15の入口導入面取りが存在しないことを実体形状の照合で確認しています。 そのため、中央断面の嵌合、ガタ、係止・解除の候補選びには使えますが、v4本体の入口の当たり方や挿入感まで同一には再現しません。候補の個別片で本体と同じ局所造形姿勢を確認した後も、最後にv4本体で入口と挿入感、ロック・解除、保持強度を確認してください。

1 寸法の基準と精度の考え方

Apple の公式アクセサリー設計資料にある 41mm 系雄ラグの代表値は、幅 32.11±0.06、高さ 3.21±0.03 です。中央ラッチの突出は 0.38±0.13 です。これらはバンド側の雄部品の図面値であり、今回造形する雌側にそのまま適用する公差ではありません。SMALL という名称だけで全世代・全バンドの完全互換を保証せず、最終的には使用する実バンドで確認してください。Apple公式資料

JLC3DP の公開設計ガイドでは、100mm 以内のモデル公差は SLA が ±0.2、MJF/SLS が ±0.3。穴公差はいずれも ±0.3 です。これは製造条件による一般的な目安で、今回の曲面溝、局所的なラッチ受け、角の形状までその値で必ず仕上がるという個別保証ではありません。反りや変形、塗装の影響も別に考える必要があります。2024年の比較記事にある SLS ±0.2 の記載より、新しい設計ガイドと材質個別ページの ±0.3 を優先しています。JLC設計ガイド

  • 積層ピッチ 0.10 と、完成寸法の精度 ±0.10 は別物です。
  • CADでR1.00の丸みやC0.15の入口面取りが存在することと、印刷品がその形を忠実に再現することは別です。造形の局所分解能、段差、角の丸まり、後処理が影響します。一般公差や大きな基準片の測定値から、曲率・微小面取り・ラッチの再現性を保証しません。
  • 同じ CAD、材質、姿勢でも、個体差と系統的な縮みの両方が生じ得ます。
  • 家庭 PETG で合った補正値を、そのまま MJF、SLS、SLA に転用しないでください。
  • 材質、造形方向、後処理が変わったら、嵌合条件も再確認します。

v4 の H と P の意味

v4 の H は受け溝の全高です。Pk11 を参考にした基準 H3.50mm に、height_offset を加えて変化させます。補正量は全高への加算値で、以前の片側拡張パラメータ C とは定義が異なります。 対称に高さを変える場合、上側と下側の移動量は各々その半分です。溝の奥行は3.50mm、入口の口高さは2.50mmで固定します。P は中央ラッチ開口の長辺幅で、短辺は2.25mmです。最終値は生成manifestを優先してください。

H3.50はAppleの雄ラグに隙間ゼロで一致する基準ではありません。公開アダプター由来の出発形状です。H3.50と雄ラグ高3.21の差だけでも0.29mmありますが、曲面形状とラッチ位置が異なるので、この差だけから実際の遊びや掛かりを保証することはできません。

HやPのCAD補正値は、完成品で許してよいガタの量ではありません。 ラッチは突出量が小さく、上下方向の遊びが大きいと、溝に入っても保持の掛かりを失うことがあります。大きなHの試験片は「どこから入るか」を探す診断用でもあり、そのまま装着用として採用しないでください。単に穴を大きくするだけでは、保持強度は改善しません。

破断伸びや引張強度だけで、今回の薄い保持壁の寿命は決まりません。角の丸まり、ラッチが当たる面の摩耗、局所的な肉厚も影響します。JLC の一般設計ガイドでは、突起、位置決め、スナップなどの厚みは 1.5mm 超を推奨しています。一般壁厚の最小値で保持部まで設計できるとは限りません。単体試験片の公称後壁1.50mmと、v4本体の連続したケース側支持材の厚さは別です。v4本体に旧形状の薄い先端値や単純な受け箱の肉厚を当てはめません。局所面取りや入口付近も含め、全箇所の最小肉厚を一つの公称値で保証せず、最終CADと製造可否を個別に確認します。JLC設計ガイド

最終v4本体の局所肉厚

最終本体のCAD断面確認では、中央の前側保持リップは上側約1.59mm、下側1.50mm、中央溝の上壁・下壁は約2.09mm・2.00mmです。これらは特定断面の値で、本体全域の最小肉厚ではありません。

左右の開口端では、外側R1と入口C0.15が重なり、最先端の縁が上側約0.94mm、下側約0.85mmまで薄くなります。 この短いテーパーは横方向の入口末端約0.15mmに限られ、中央の保持壁とは別です。開口端の値を中央保持壁の厚さに読み替えず、中央の値を使って「全箇所1.5mm以上」ともしないでください。

入口の薄い縁は実造形・実使用で未検証です。PETGでもJLC3DPでも、冷却や後処理が済んだ後、欠け、白化、ひび、バリ、粗れを確認してから挿入します。サポート除去や研磨で縁をさらに削らないよう注意し、縁に損傷があるものは嵌合合格として扱いません。薄い入口の製造可否も、JLC3DPの一般公差や中央壁厚だけでは保証できません。

長時間肌に触れる用途については、材料名だけで安全性を断定できません。JLC の完成品、染料、洗浄、仕上げを含む皮膚接触への適合性は未確認です。必要な場合は、その注文条件での適合資料を確認してください。レジンの無塗装指定も、洗浄や硬化が不要という意味ではありません。

3 最初は6条件の縦積み一体ブロック

最初の試作では、stacked_test の一体ブロック1個を印刷し、同じバンドを各段へ順に挿入して比較します。6条件を別々に印刷する必要はありません。通常向きと印刷向きの別ファイルがある場合は同じ治具の代替版なので、両方を二重に印刷しません。

一体版の使い方は stacked_test/README_JA.md、主ファイルと初回数量は stacked_test/manifest.json、条件一覧は stacked_test/conditions.json にあります。寸法・干渉・STEP再読込みのCAD検査結果は stacked_test/validation.json を参照してください。6つの元STEP試験片を共通の背骨で結んだ1ソリッドです。切り離す前提のランナーではありません。刻印されたIDで各段を識別します。

個別ファイルと追加試験

通常の export にある個別6種類の試験片は、一体ブロックが印刷しにくい場合、特定の条件だけ作り直す場合、材料や姿勢を変えて比較する場合のバックアップです。個別ファイルを使う際は parts_manifest.csv の寸法を参照してください。初回に一体ブロックと個別一式を両方印刷する必要はありません。

JLC3DPなどで個体差を追加評価したい場合のみ、個別6種類を各1個と、中心条件H350を追加2個にする従来案を使えます。合計8個、そのうちH350が3個です。中心条件の複製は同じ形状・向き・材質・後処理で揃え、寸法違いの効果と個体差を区別します。これは一体ブロック1個の初回試験とは別の任意の工程です。同一バッチ内の3個だけで、別バッチの再現性まで保証することはできません。一体ブロック自体の再現性を調べる場合は、同じブロックを複数造形して同じ段どうしを比較します。個別H350の3個は、その代用にはなりません。

一体化すれば必ず安くなるわけではありません。共通背骨の材料、造形外形、最低料金、検品、後処理、梱包、送料で総額は変わります。材料費だけでなく実見積もりで判断してください。

一体ブロックの造形方向

一次試験では stacked_test/export/receiver_stack_6_PRINT_axisZ.stl を使います。スライド軸Xをプリンタの造形＋Zへ向けた一体ブロックで、目安の印刷外形は117.5×9.85mm、高さ34.5mmです。5mmブリムを周囲に付けると約127.5×19.85mmの範囲になり、Adventurer 3 の150mm角ベッド内に収まる計算ですが、スライサー上の使用可能範囲と配置を確認してください。

  • 各段は元の組立姿勢で20mmピッチ、段間の空きは12.5mm、最下段の下は10mmです。「縦積みの見た目」と実際のプリンタZ方向は同じではありません。
  • receiver_stack_6_study は説明・観察用の立てた向きです。高さ117.5mmの姿勢でそのままFDM印刷せず、一次試験は PRINT_axisZ を使用します。スライサーの自動整列で別の面を下にしないでください。
  • レール内面へのサポートを避ける向きです。スライサーの自動サポートが溝やラッチ開口に入っていないか確認し、必要なら無効化・除外します。
  • 初回は0.10mm層高、外周4周、充填100%、5mm程度のブリムを出発案とし、他の温度・速度条件は上表を使います。条件を変えた場合は記録してください。
  • 一体ブロックには、本体側面造形版と同じ30°の局所回転を入れていません。溝内部の支持回避と刻印の読みやすさを優先した条件です。したがって、ブロックで候補を選んだ後、その条件の個別 _print_axisZ 試験片で本体と同じ局所姿勢を再確認してから、本体を造形します。この個別片にもv4本体のC0.15入口面取りはないため、入口の挿入感は本体で確認します。
  • ブロックと個別片は背後の剛性、造形位置、断面の機械X/Y方向が異なります。条件を同一視しません。サポート配置、初層接着、実際の造形とバンドの係止・解除は未検証です。

一体ブロックは、ひとつのバンドを各段に順番に入れて試します。先に解除窓へ操作できることを確認し、無理に押し込まないでください。段間のCAD上の空きがあっても、指や実際の解除工具が使える保証ではありません。直径1.5mmのL字型鈍端プローブの通り道はCADで干渉なしを確認していますが、実バンドの形状や操作性の検証ではありません。実際に使うバンドと、傷を付けない解除方法を先に確認します。

湾曲ケースと個別試験片の造形方向

本体は、元の湾曲した下面をベッドへ無支持で平置きできる形状ではありません。初回のFDM試作は、左右の受けに共通するスライド軸Xを、プリンタの造形Zへ向ける側面置きを第一候補にします。断面が造形XY面に現れるため、レール内面へのサポート接点を避けやすくなります。

  • 通常の本体STLは組立座標のままです。名称に _print_axisZ が付くSTLは、側面置き用に回した同じ部品の代替ファイルです。通常版と両方を注文・印刷しないでください。
  • 接地安定性のため、5mm程度のブリムとケース外側への支持を出発案とします。ブリムを機能面へ付けず、支持の接触面は取り除ける位置に置きます。
  • レール内部と中央ラッチ開口にはサポートを入れない方針で、スライスプレビューを確認します。自動サポートが内部へ生成された場合は、設定を変えて再確認します。
  • 受けは本体の湾曲に沿って30°傾けて配置されています。試験片を本体の代わりに評価するには、スライド軸だけでなく、この局所断面の向きも本体側と合わせます。単に試験片の平らな面をベッドへ置いた結果は、異なる姿勢の結果です。
  • _print_axisZ の試験片は、本体の正側受けに合わせて局所X軸まわりに−30°傾けてから、本体と共通のY軸まわり−90°回転を行う向きです。通常の試験片STLはCAD確認用の元座標を保っているため、同じ造形向きだとみなさないでください。
  • 寸法違いと中心条件の複製は、同じ向き・材料・層高・支持設定で比較します。別の向きも試す場合は、その条件を分けて記録します。

この造形姿勢はCAD形状からの試作案で、スライサーの支持配置、積層経路、初層接着、実造形は未検証です。 外周が連続しているか、薄肉が消えていないか、上側の溝や開口に無理なブリッジがないか、支持が外せるかを印刷前に確認してください。受け試験片で挿入・保持・解除を確認してから、本体へ進みます。溝に入るだけで本体を採用せず、ラッチ保持と湾曲腕との接続部の強度は別に検証します。

下準備

  • サポート接点、シーム、糸引き、初層のはみ出しを、溝内面やラッチ保持面に残さないようにします。
  • ノズル径、初層校正、流量を確認し、濡れた材料による糸引きや表面荒れがあれば銘柄指定に従って乾燥します。
  • ラッチ保持面を削る前に写真と実寸を記録します。研磨で偶然合ったものと、印刷したままで合ったものは別条件として扱います。
  • 0.10mm 積層でも、ラッチの掛かりや耐荷重が保証されるわけではありません。

6 試験の進め方

最初は時計本体を落とさない机上環境で、実際に使うバンドを確認します。無理な力で押し込まず、きつい場合はそこで中止してください。

  1. 印刷後に十分冷え、洗浄や仕上げが終わった状態で試験片 ID を確認する。
  2. 溝、ラッチ開口、バリ、ひび、粉末やサポート残りを観察し、加工前の写真を撮る。
  3. 測定できる箇所の実寸を記録する。可能なら入口・中央・出口を確認する。
  4. バンドが指定方向から滑らかに入るかを確認する。
  5. ラッチが所定位置に掛かるか、上下に動かした状態でも勝手に解除されないかを確認する。
  6. 通常の操作で解除できるかを確認する。
  7. 着脱の回数を記録し、ガタ増加、角の摩耗、ひび、解除不良がないか再確認する。
  8. 形状と機構が通った後に、別途、管理した保持・耐久試験を行う。

ノギスで測りにくい内溝を、無理な測り方で高精度に測れたことにしないでください。使用した測定器、測定箇所、分解能、測れなかった箇所も残します。手で抜けないという結果だけでは、日常使用の荷重や衝撃に耐えることの証明にはなりません。

追加の抜け止めを別途設ける場合も、それ自体の締結・強度確認が必要です。v4の納品モデルに旧版の任意ねじ止めゲートが含まれるとは想定しません。ラッチの掛かりが不十分な状態を、別の抜け止めの存在だけで合格としません。
