CURVE-05：キャッチの張り出しを短くした試作ケース

M5Stopwatch用CURVE04から、Apple Watch小型系バンド受けを本体側へ寄せた改訂です。バンドの左右幅ではなく、丸いケースから外側へ出る長さを短縮しています。

実物のバンド適合、ロック・解除、保持力、耐久性は未検証です。装着前に、時計を付けずに確認してください。

変更寸法

  • 本体外形は約 56.13 × 69.67 × 18.72 mm（時計本体を含まないケース単体）。
  • 受けを片側 2.50 mm内側へ移動。全長 74.675 → 69.675 mm、合計 5.00 mm短縮。
  • 元の30°傾斜に沿って移動するため、受け中心は同時に 1.443 mm上方へ移動します。
  • 公称R27.5の丸い本体を基準にした片側の張り出しは 9.837 → 7.337 mm、約25%減。これは受け全体の横幅ではありません。
  • 受けの左右幅34.50、溝全高H3.50、溝奥行3.50、出口高2.50、中央穴P5.50 × 2.25 mmは変更していません。
  • 元の腕側接触曲線を残し、不要になった旧ストラップ耳の先端を除去。短縮で下に残る小さな突起を解消するため、新設部の下側を0.75 mm厚くしました。局所下面は−3.75 → −4.50 mmです。
  • 外側R1.00丸みと入口C0.15を維持。上面の幅移行曲線は局所G2条件を維持しています。下側面に残る面の境界まで、全面接線連続という意味ではありません。
  • 隠れる床面の識別はCURVE-05、彫刻深さ0.25 mm、残る床厚3.25 mmです。

既存の試験部品について

今回のCADパックは変更した本体の改訂分です。前回の6条件一体試験ブロック、個別試験片は変更しておらず、そのまま使います。

  • 一体試験ブロックでH/P条件を選ぶ。
  • 選んだ条件を、本体と同じ局所造形角度の個別片で確認する。
  • 最後に短縮本体で、バンドの挿入、ガタ、確実な係止、裏穴からの解除を確認する。

既存の試験部品には本体の有効なC0.15入口面取りがなく、今回厚くした下面や実際の本体への取り付けも再現しません。断面嵌合・ラッチ寸法を絞るためのものです。実バンドの形状や保持力は、最終本体でも必ず確認してください。

JLC3DP材質・発注設定とAdventurer 3 + PETGの基本設定は、前回配布した印刷ガイドを継続使用できます。ただし前回ガイドの本体外形・受け位置・下側肉厚はCURVE04の値です。今回の寸法はこのREADMEとCAD_CHECKS.jsonを優先します。造形姿勢、サポート、スライサー、発注先の受入れは未検証です。

肉厚と制約

上側の中央前縁は約1.594 mmのままです。今回の下側補強は外側形状のみで、溝・中央ラッチの位置や寸法を広げるものではありません。R1と入口C0.15が交わる最外端の縁、元から薄い磁石ポケット底などを含め、全域の最小肉厚を保証しません。位置別の確認値はCAD_CHECKS.jsonを参照してください。

短縮量は幾何検査で余裕を確認した試作値で、物理的な最短寸法や強度限界ではありません。欠け、白化、ひび、バリ、異常なガタ、解除不良があれば使用を中止し、寸法や造形条件を調整してください。

再生成

Python 3.12、CadQuery 2.7.0、NumPy 2.3.5で検証。彫刻にはDejaVu Sansフォントが必要です。

pip install -r requirements.txt
python build_case.py

標準値は片側2.50 mm短縮です。実測した試験片結果に応じて、たとえば次のように溝の全高補正と中央穴幅を変更できます。

python build_case.py --inward 2.50 --height-offset -0.10 --pocket-width 5.50

変更後は、干渉・肉厚・印刷適合を再検査してください。任意の--inward値に対して安全性を保証するスクリプトではありません。parameters.jsonを直接編集しても生成形状へは反映されません。生成時にexport/を上書きするので、測定済みの版は別保存してください。
