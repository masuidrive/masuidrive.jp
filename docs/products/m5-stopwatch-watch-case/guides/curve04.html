CURVE-04：M5Stopwatch / SMALL Apple Watch band 試作ケース

元の BANDBASE2 の腕側カーブを残し、端の24 mmストラップ用ラグをApple Watch小型系バンドの受けに変更した、形状・寸法検証用CADです。

実物のバンド適合、ロック・解除、保持力、耐久性は未検証です。まず一体型差込口試験ブロックで条件を絞り、時計を付けずに確認してください。

最初に使うファイル

  1. stacked_test/export/receiver_stack_6_PRINT_axisZ.stl：6条件を縦積みにした一体型試験ブロック。初回は1個。
  2. 条件が絞れたら export/coupon_*_print_axisZ.stl：本体と同じ局所造形角度の個別確認片。
  3. 最後に本体。export/m5_small_band_curve_v4.step と .stl、造形候補向きの _print_axisZ.stl。

export/assembly_reference_DO_NOT_PRINT.step は時計本体を含む組立参照です。印刷しないでください。標準STLと姿勢違いSTLも同じ部品なので、両方を発注しません。

素材、JLC3DP発注条件、Adventurer 3 + PETG設定、合否の記録方法は PRINT_GUIDE_JA.md。

V4で直した箇所

  • ケースの肩から受けに続く広い上面を、元の肩の平面・丸みにつながる形へ再構成。以前の横断段差と角張った切り欠きを解消しました。
  • 元のBANDBASE2の外縁に合わせ、新設部の外側上縁・前縁・端角を 実際のR1.00 mm曲面 で丸めています。画像だけの丸め処理ではありません。下面の元曲線を守るための切り取り部など、すべての外縁が一律R1という意味ではありません。
  • 肩の幅の移行は、元の側面勾配につながる5次ベジェ曲線で構成。指定した移行曲線の両端で勾配と曲率が連続するG2条件を使っています。ケース全体の全接合がG2という意味ではなく、下側面に元の曲面との微かな勾配切替線が残ります。CAD法線の抜き取り検査では上側の接続差は約0.027°、残した中・下側面の接続差は最大約18.8°です。全体の接線連続は主張しません。
  • 左右のスライド入口4か所には C0.15 mm の導入面取り。幅方向の外端、|X|17.10〜17.25 mmだけが対象です。
  • 中央ラッチ穴、保持に使う溝断面、受け位置と30°の傾斜は変更していません。
  • 元の時計座面・床・磁石ポケット・スピーカー穴・係止爪・腕側接触曲線を保護。新しい肩の下面にだけ微小な逃げを設け、元の接触曲面を残しています。
  • 隠れる中央床に識別名とH/Pを0.25 mm彫刻。残る床厚は3.25 mmです。

新設受けの中央前縁は上約1.594 / 下約1.500 mm、中央の溝の屋根・底は約2.094 / 2.000 mmです。R1と入口C0.15が交わる最外端の開口縁は、上約0.944 / 下約0.850 mmまで薄くなります。短い入口のテーパー部で、中央の係止壁ではありませんが、欠け・毛羽立ち・変形を実物で確認してください。

新設受けの肉厚は位置によって異なります。元から薄い磁石ポケット底、入口の角処理などを含む「ケース全体が1.5 mm以上」という意味ではありません。

本体外形は約56.13 × 74.67 × 19.51 mm。元のBANDBASE2は約56.13 × 71.61 × 19.09 mmで、幅は同じ、全長+3.06 mm、ケース単体の高さ+0.42 mmです。時計を含む組立寸法ではありません。

試験条件と本体の違い

H＝溝の全高、P＝中央ラッチ穴の左右幅。溝奥行3.50、出口高2.50、穴奥行2.25 mmは固定。

  • H340 / H350 / H360 / H370：H3.40 / 3.50 / 3.60 / 3.70、P5.50 mm
  • P535 / P565：H3.50、P5.35 / 5.65 mm

H補正は基準3.50 mmからの全高補正です。片側の隙間や許容ガタではありません。基準以外はわずかな楕円断面です。Hが大きい条件は穴縮みの診断用で、緩いものをそのまま採用しないでください。

一体ブロックと個別試験片は、先に渡したものと同じ形状です。既存試験片にはV4本体の有効なC0.15入口面取りがありません。 中央の断面嵌合・ガタ・係止を絞る試験に使えますが、最終本体の挿入開始時の感触まで完全には再現しません。

一体ブロックは本体側面造形と同じ30°の局所回転を入れていません。選んだ条件を個別 _print_axisZ 片で確認し、同じ材質・姿勢・後処理で本体を確認します。parts_manifest.csv の8個案は、H350を3個にする任意の個体差試験で、初回必須数量ではありません。

検証と画像

実CADからの画像：renders/。元のBANDBASE2との同じカメラ・縮尺での比較：comparison/renders/。

CAD検査では、単一ソリッド、時計との干渉なし、両端のバンド経路と解除用プローブ経路の障害なし、取り付け機能面と腕側曲線の保持を確認。STLは数値的退化面だけを整理し、境界・非多様体・向き不整合エッジなしを確認しています。詳細は CAD_CHECKS.json、mesh_validation.json、各試験治具の検証ファイル。

これは実物検証や装着安全性の保証ではありません。Pk11参考STLには単位情報がなくmmと仮定しており、小型系バンドの実適合も未確認です。裏の穴からバンド自身のラッチを直接押す構想で、独立した解除ボタンやばねはありません。

再生成

検証環境：Python 3.12、CadQuery 2.7.0、NumPy 2.3.5。画像はBlender 4.3.2。彫刻にはDejaVu Sans、比較画像の日本語にはNoto Sans CJK JPフォントが必要です。

pip install -r requirements.txt
python build_case.py
python build_case.py --height-offset -0.10 --pocket-width 5.50
python build_receivers.py
python stacked_test/build_stack.py
blender --background --python render_cad.py

本体は build_case.py、個別試験片は build_receivers.py が編集可能な設計元です。parameters.json は生成記録で、直接編集しても反映されません。一体ブロックは同梱した固定STEP試験片から再生成します。個別片の設計値を変えた場合、一体ブロックの入力STEPも意図して差し替える必要があります。

生成時は export/ を上書きします。測定済みの版は別保存してください。スライサーでのサポート・接地・実造形は未確認です。
