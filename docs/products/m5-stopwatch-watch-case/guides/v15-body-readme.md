ネジを未測定のため、寸法確定済みの製造承認データではありません。購入・注文・実機分解は行っていません。

## 変更
V14の平坦な高さ層を0.50 mm詰め、背面ネジ2本に合わせて局所補強座を追加しました。磁石穴は作っていません。外周の受け形状を維持し、横荷重を受け形状で支え、ネジで本体の浮き上がりを抑える方針です。実際の荷重分担は未検証です。

- 本体背面の座面：Z=3.99 mm（V14は4.49）。
- 中央の腕接触基準から本体上端：19.49 mm（V14は19.99）。
- 受けの下側突出まで含めた組立外接高さ：23.4095 mm。上の19.49とは基準が異なります。
- ホルダー単体外形：55.6999 × 55.6282 × 12.6095 mm。
- ネジ中心：X=±20、Y=0、中心間40 mm。
- 補強座：φ8、底面Z=0.80、上面Z=3.99。
- 仮の軸穴：φ2.4。仮の頭逃げ：φ4.4、深さ1.5。
- 頭座面：Z=2.30。座面上の肉厚1.69 mm。頭逃げ外側の局所肉厚3.19 mm。
- ネジ頭の実高さが1.5 mmを超える場合、現状の逃げには収まりません。径・高さ・工具の適合を確認してください。

## バンド位置と音道
写真の挿入位置を、二つの丸印と切り欠き側から数えたB6と対応付けています。添付ゲージ表ではB6=A6=C2K3（C4基準）、H4.20/P6.00です。本モデルはその既存V14の受け内形・ロック・位置・31°を保ちます。ゲージ成功とフルサイズ本体の造形成功は別です。

V14の音道を本体とともに0.50 mm下げ、相対形状を維持。背面音孔から+Y外周へ抜け、腕側の貫通穴はありません。幅11×高さ約0.8 mm、12断面の幾何学的自由断面積は約8.8 mm²。皮膚、袖、柔らかいバンド、造形誤差による閉塞や音量は未確認です。

## 検証と限界
- CAD：有効な単一ソリッド。提供本体5ソリッドおよびバンド空間との交差体積0。
- 局所補強座とバンド空間の最短距離：約8.94 mm。
- 音道領域は高さ変更後のV14と形状差分0。
- バンド空間最高点から座面までのZ方向差は1.00993 mm。受け屋根の縦方向49有効サンプル最小は約1.0106 mm。全形状の最薄肉厚・法線方向の一様肉厚を保証する数値ではありません。
- STL：閉じた単一連結メッシュ、境界辺0、非多様体辺0、向き矛盾0。CAD体積との相対誤差約0.00757%。全三角形ペアの自己交差網羅検査や構造解析ではありません。
- 強度、樹脂ボスの寿命、ネジ締結、落下、振動、肌への当たり、実物公差は未検証。
- 0.8 mm音道の造形・清掃と、約1 mmの受け屋根を製造者に確認してください。JLC3DPやAdventurer 3の造形保証、機種用完成印刷ジョブではありません。収縮補正は追加していません。

## ネジを確定する前に
公式図面が示すのは中心間40 mm、穴2-φ2.2／2-φ4です。M2や首下長・ピッチ・締付トルクは記載されていません。φ2.2という穴径だけでM2と決めないでください。
既存ネジの径・ねじ山（樹脂用タッピングか機械ねじか）、首下長、頭径と高さ、受けの構造を実物で確認し、同じねじ山と元の噛み合いを保つ長さを選びます。提供逆設計CADは元の頭座面が本体裏面から2 mm奥で、この仮設計の長さ増分は約3.69 mmですが、これは実測済みの購入指定ではありません。長すぎるネジは底付き・ボス割れ・内部損傷のおそれがあります。長さや締付トルクを決め打ちしないでください。
