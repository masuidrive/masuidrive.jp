6条件を縦にまとめた、一体型バンド受け試験ブロック

旧版資料です（2026年10月15日追記）。Adventurer 3・PETGで印刷した旧30°版は6条件とも挿入できませんでした。現在は差込空間を広げた試験片v2で再試験する段階です。v2に対応するケースは未作成で、このページのH/P・ケースIDとの対応はありません。以下は旧版の保存資料です。

現在の6種類の受け形状を変更せず、背面の共通支持部でつないだ試作ブロックです。まずこの一体品を1個印刷して、手元のバンドで寸法候補を絞る使い方を想定しています。バンド装着用の最終製品ではありません。

実物の印刷、バンドの挿入・係止・解除、強度は未検証です。 CADの通路検査は、手元のすべてのバンド・指・工具が使えることを保証しません。無理に押し込まず、硬い場合は途中で止めてください。

最初に使うファイル

  • export/receiver_stack_6_PRINT_axisZ.stl：推奨の印刷向き。スライド溝の長手方向がプリンタZです。底面Z=0、外形は約117.5 × 9.85 × 34.5 mm。STLはmmで読み込み、100%スケールにします。
  • export/receiver_stack_6_PRINT_axisZ.step：同じ向きの一体ソリッド。
  • export/receiver_stack_6_study.step / .stl：説明・観察用の立てた向き。外形は約34.5 × 9.85 × 117.5 mm。これを長い縦姿勢のままFDM印刷することは推奨しません。 各段の横向き溝や張り出しにサポートが必要になる可能性があります。
  • backup_individual/：既存の6種類の個別STLと個別の代替印刷姿勢STL。条件ごとに再確認するための予備です。対応する変更前の個別STEPはinputs/にあります。

一体ブロックと6種類の個別品を、最初から全部印刷する必要はありません。一体品を1個試し、必要な条件だけ個別品で確認します。再現性を調べる場合、一体ブロックの再現性はブロック全体を複数回印刷して比べます。

6段の条件

観察用の立てた向きで、下から次の順です。Hは溝の全高、Pは解除窓を兼ねる係止開口の幅です。単位mm。各段の既存のH/P刻印を残しています。

  1. H340：H3.40、P5.50
  2. H350：H3.50、P5.50（基準）
  3. H360：H3.60、P5.50
  4. H370：H3.70、P5.50
  5. P535：H3.50、P5.35
  6. P565：H3.50、P5.65

溝の深さ方向は3.50、ネック開口高さは2.50、係止開口の奥行きは2.25で共通です。同じH350をこのブロックに3段入れてはいません。6つの異なる条件を1段ずつ使います。詳しい条件はconditions.jsonにあります。

支持部とアクセス

  • 各受けの厚さ7.5 mmに対して段ピッチ20 mm。隣接する受けの間は12.5 mm空いています。
  • 最下段の下面は底端から10 mm上。最下段にも下側から解除する空間があります。
  • 観察向きの挿入方向はXの左右、バンド本体が出る向きは＋Y、解除窓は各受け下面の−Zです。左右のスライド入口は両方開いています。
  • 背面の板はY−7.1〜−5.3の厚さ1.8 mm。左右端の傾斜付き接続部もY−2.65より後ろに限定しています。溝の通路、バンドが出る正面、中央の解除窓には材料を足していません。
  • ラベルがある中央の張り出し（X±10 mm付近）には背骨を重ねず、刻印を覆っていません。
  • 直径1.5 mmの先端を丸めたL字状プローブを想定し、正面の段間から入り、解除窓へ真上に押し上げる経路をCADで確認しました。縦方向のチェック区間は受け下面−5〜＋2.5 mm、正面側はY＋15 mmまで開放されています。全6段で、この経路とモデルの交差体積はゼロです。

解除するときは、一度に1本だけを試します。入れる前に解除窓の位置と、抜く操作ができることを確認してください。指が入らないときは、先端の尖っていない細いプラスチック工具などで窓から解除部を押します。工具の太さ・形により使えない場合があります。バンドを強く引きながら無理に解除せず、硬い条件は評価を中止します。

「一体化したから保持力が上がった」「同じ段間なのでどの指も入る」という保証はありません。窓を隠さないことと、規定の細い工具経路が開いていることを確認したモデルです。

Adventurer 3＋PETGでの印刷

  1. PRINT_axisZ.stlを使います。長いブロック全体はベッド上で横向きになり、各溝だけがプリンタZ方向に伸びる配置です。モデルの自動整列で別の面を下にしないでください。
  2. 推奨姿勢は溝の内面にサポートを入れずに済むことを狙っています。背面の端部は約45°の傾斜で立ち上がります。ただし、既存のラベル張り出しや微小な丸みを含むため、スライサーでオーバーハングと接地を確認し、全体が必ずサポート不要とは断定しません。サポートを使う場合も溝・係止部・解除窓を傷つけない設定にします。
  3. 117.5 mmの細長い接地形状です。使用済みPETG設定で、必要なら外側にブリムを付けます。ブリムはスライド入口や溝に残さないよう処理します。概算で周囲5 mmのブリムを付けた外形は127.5 × 19.85 mmですが、実際のスライサーでベッド内に収まることを確認してください。
  4. 0.4 mmノズルを想定しています。温度・速度などは材料とプリンタで実績のある設定を優先し、層高、XY補正、象足補正、流量を記録します。大きな補正を入れて条件差を消さないようにしてください。
  5. 冷却後、文字と溝の入口を確認してから試します。溝内面を削ってから条件を比べると比較できなくなるため、除去したバリやサポートがあれば記録します。

重要な向きの違い： この一体ブロックの推奨ファイルには、湾曲ケース側の30°の傾斜回転を入れていません。垂直な溝の印刷性を優先した初期の形状探索用です。本体と同じ局所造形姿勢・支持条件の最終確認には、絞った候補の個別試験片やケース本体を使ってください。ブロックの結果だけで湾曲ケースでの適合を保証しません。

JLC3DPなどへの比較用

同じ一体STEP/STLを候補にできますが、製造可否、最小肉厚判定、造形姿勢、後処理、1部品としての課金、見積金額は未確認です。一体化で必ず安くなるとはしていません。MJF PA12やSLAで比較するときも、実際の造形軸・研磨・硬化・清掃などの条件を記録してください。

受け本体は元の形状のままです。名目の背面壁1.50 mmだけを見て「全箇所で最小肉厚1.5 mm以上」とは表現しません。丸めた入口の縁には薄くなる部分があります。背面の共通支持板1.8 mmも、受けの局所肉厚を増やすものではありません。

編集・検証

  • build_stack.py：CadQuery 2.7用。inputs/に固定した6個のSTEPを読み込みます。親のケース生成スクリプトは実行しません。
  • Pの段ピッチ・最下段高さ・背面支持寸法を編集できます。段間隔を小さくすると工具やバンドに干渉する可能性があるため、変更後はCADチェックと実物アクセスを再確認します。
  • python build_stack.pyで一体STEP/STLを生成します。python check_stl.pyで出力STLの閉鎖性・面向き・部品数を確認します。
  • validation.json：一体1ソリッド、STEP再読込み、元の受け材料を削っていないこと、溝・口・解除窓・規定の工具経路・刻印部に追加支持が侵入しないことを検証。
  • mesh_cleanup.py：書出し時の数値的な縮退・重複三角形を除去し、0.00001 mm単位で頂点を共有化します。STEP形状は変えません。処理内容と処理後のSTL検査を別に記録します。
  • render_stack.py：実際の出力STLをBlender CPUで陰影表示します。renders/に全体、段間・解除側の拡大、推奨印刷向きの画像があります。render_labeled.pyは6条件の読みやすい注釈付き正面図、render_underside.pyは解除窓を下から見る拡大図を生成します。注釈は説明用で、印刷形状には含まれません。

3D表示やCAD合格は、印刷品の係止・解除・摩耗・長期強度の試験結果ではありません。
