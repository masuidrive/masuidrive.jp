# V15：Adventurer 3向け、印刷姿勢固定用の折り取り脚1本付き

## 読み込むファイル
`export/M5Stopwatch_V15_ADV3_tilt30_ONE_FOOT_ADD_SUPPORTS.stl`

**脚1本だけで造形できるモデルではありません。FlashPrintで追加サポートが必要です。実スライス・実印刷は未確認です。**
G-code、プリンタ専用印刷ジョブ、温度・積層設定は含みません。

## 形状
- 直前のV15薄型2点ネジ固定本体は変えず、元V14 ADV3版の折り取り脚だけを移植。
- 本体を組立座標からY軸−60°回転し、既存と同じ印刷姿勢に配置。差込軸と印刷Zの角度30°、ケース面とベッドの角度60°。
- 脚底は10×8×0.6 mm。接続首は元版の0.7×0.45 mm。
- 脚の最下Z=0、元ケース外縁の側面に接続。バンド受け、ロック、音道、ネジ穴、中央肌接触面には追加しない。
- 脚は姿勢維持用の犠牲形状です。接続首の造形・強度・折り取り性は未検証。除去跡が残る可能性があります。
- 元V15の足なしSTEPは inputs/V15_body.step。比較・編集用です。

外形は約32.575×55.628×51.700 mmで150 mm角内。本体の最下部はベッドから2.0 mm浮いています。足と本体の共有面積は約0.297 mm²で、弱い切り離し接続です。

## FlashPrint
1. STLをmm単位・100%で読み込み、付与された角度を維持する。
2. ビルド面の中央に水平移動。自動で面を寝かせたり、再回転したりしない。
3. 脚底の平面がベッドに接し、浮き・めり込みがないことを確認。
4. 浮いたケース各部に追加サポートを設定する。脚だけに荷重を任せない。
5. レイヤープレビューで接続首が途切れないことを確認。脚底への密着対策は材料・スライス条件に応じて検討。
6. バンド穴、ロック、約0.8 mm音道、ネジ頭逃げに除去不能なサポートが入らないことを確認。
7. 冷却後、脚を接続首で慎重に切り離す。本体やバンド受けを強くねじらない。残りを仕上げる際に機能面を削らない。

## 本体の注意
仮ネジ穴はφ2.4、頭逃げφ4.4×1.5 mm。実物のネジ径・頭径・高さ・ねじ山と長さを確認して合わせる必要があります。M2等のねじ規格、購入長、トルクは未確定です。
薄型受け上屋根の縦方向サンプルは約1.01 mm。強度・実バンド適合・音量・印刷成功の保証ではありません。詳細は BODY_DESIGN_NOTES_JA.md を参照。

## 検証
qa/validation.json と独立検証結果を参照。CADの有効性、本体材料の欠損がないこと、足の機能空間侵入、造形範囲、STL閉鎖性を確認します。これらはスライス成功や実機強度の実証ではありません。

## 再生成
CadQuery 2.7.0、numpy 2.3.5を使用。`python build.py`。
元V14脚付きデータとの差分から足を再現し、V15本体に合成します。入力CADとライセンスを同梱しています。
