条件の識別
刻印は旧刻印も含めて全て削除しました。
本体の背骨の端にある大きい半円切欠き（直径6mm）が、条件1側の目印です。
支持材を取り除いても、この切欠きは本体に残ります。
切欠きに近い受けから順に1→2→3→4→5→6です。左右という呼び方には頼りません。
条件6側には切欠きがありません。印刷物の写真は切欠きも一緒に写してください。

変更内容と注意
・楕円溝の半軸に同じ増分を足しました。楕円の厳密な法線オフセットではありません。
・入口は上下に拡大。中央キャッチ/解除開口は幅・奥行きを両側に拡大。
・挿入する長手方向の全長34.5mm、受けの外周、受け間隔20mm、姿勢は変更していません。
・旧刻印の浅い凹みを埋めています。内部の切削形状には影響しません。
・拡大により保持に効く縁が薄くなり、中央開口も大きくなるため保持力が落ちる可能性があります。
・両端の差込入口に全条件共通の0.15mm面取りを付けています。
  楕円溝の縁2本とネック入口上下4面が対象です。
  表の寸法は入口面取りを除いた直通部分の寸法。両端から0.151mm以上内側は
  面取りによる形状変更がないことをCAD差分で確認しています。
・寸法はCAD公称値。印刷実測値やメーカーの保証公差ではありません。

印刷
前回のPETG設定を基本に、今回の寸法変更以外の比較条件はなるべく固定してください。
0.4mmノズル想定。層高0.15mmが候補ですが、前回と変える場合は記録してください。
温度・速度は実際のフィラメント/装着ノズルの範囲内で、いつもの設定を使用。
モデルに0.4mm台座・支柱・細い連結タブを含みます。自動サポートはOFFから確認。
自動ラフトもOFFから確認し、接着が必要なら追加ブリムは可。
スライス後、支柱1mm・接触タブ0.45mmが消えないこと、差込口にサポートが
入っていないこと、傾いた溝の上側と最初の数層をレイヤープレビューで確認してください。
過押出しや糸引き・PETGの盛り上がりが原因なら、寸法変更だけでは直らないことがあります。
この版に水平膨張や全体倍率補正を追加すると表と対応しなくなります。

支持材
背骨の外側だけを支持。前版と同じ支柱間隔/60個のタブ、下端の連続支持リブです。
鉛直隙間0.60mm、タブ幅0.45mm、長さ0.7mm、鉛直食込み0.12mm。
PETGでは溶着することがあります。十分冷えてから保護メガネを使用し、支柱を小分けに切除。
一気にねじって剥がさない。内部レールは最初の比較の前に削らないでください。

結果の記録
1. 無理に押さず、入口/途中/最後のどこで止まるか、どちらの端から入れたかを記録。
2. 完全に挿入できるか、抜去できるか、キャッチがロックするかを別々に記録。
3. ロックしてもガタ・抜けやすさ・解除のしやすさを確認。挿入成功だけで時計を装着しない。
4. 6条件全て入らない場合、止まる位置と切欠きが写る写真、印刷設定を残してください。
試験ブロックで合っても、本体ケースの印刷姿勢/強度/嵌合を保証しません。
