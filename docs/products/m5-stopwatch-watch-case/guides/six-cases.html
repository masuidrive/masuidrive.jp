試験ブロックに対応する6種類のCURVE05ケース

先に6段試験ブロックでサイズを合わせ、合った段と同じH/Pのケースを1種類だけ印刷してください。6個のケースを全部印刷するためのセットではありません。

2026年10月13日現在、実物の印刷・バンド適合・係止/解除・保持力・耐久性は未テストです。

選び方

  1. 既存の6段試験ブロックに、使うバンドを挿入して確認します。「入る」だけでなく、ガタが過大でないこと、中央ラッチが係止すること、裏穴から解除できることを確認します。
  2. 合った段の実際のH/P数値刻印を読み、下の表でIDを選びます。試験ブロックには「H3.40 P5.50」などの数値が彫刻されています。H340などの短いIDは、比較画像・ファイル名のラベルです。
  3. 対応する export/CURVE05_<ID>_print_axisZ.stl を1個印刷します。ケースの時計に隠れる面にも、IDと同じH/P数値を2行で彫刻しています。
  4. 時計を付けずにケース単体で再確認し、その後に時計を取り付けます。ラッチが曖昧、簡単に横へ抜ける、白化・ひび・欠けがある場合は装着しません。

HとPを別々の段から組み合わせないでください。このセットは下記の6組です。どの組も適合しない場合、近いIDを推測して選ばず、実測値に基づいて条件を追加してください。

単位はmm。CSVは case_parameters.csv。Hは溝の全高で、片側クリアランスや許容ガタではありません。Pは中央穴の左右幅です。溝奥行3.50、出口高2.50、中央穴奥行2.25 mmは全条件で固定。H3.50以外の溝断面は高さだけを変えた楕円です。大きいHを「緩くても安全」と解釈しないでください。

共通のケース形状

すべて最終短縮版CURVE05を基準としています。全長約69.675 mm、左右のレール幅34.50 mm、受けの傾斜30°、外側R1、入口C0.15、元の取り付け部と腕側カーブは共通です。外観・取り付け部を拡大縮小していません。

H350の嵌合形状は前回の標準CURVE05と同じです。ただし、このセットでは識別用の刻印を「CURVE05 / H350」「H3.50 P5.50」に変更したため、旧STEPとファイル全体が同一ではありません。元のCURVE05は上書きしていません。

本体接面の中央床だけを深さ0.25 mmで彫刻し、床厚3.25 mmを残しています。磁石ポケットや係止爪の薄い部分には彫刻していません。

印刷と適合確認の注意

  • 本体全体の倍率は100%。倍率でレールを合わせると時計の座面まで変わります。
  • できるだけ試験ブロックと同じプリンタ・材質・層高・設定・後処理を使います。造形のばらつきがあるため、同じ公称値でも現物は完全一致しません。
  • _print_axisZ.stl はスライド軸を造形Zへ向けた候補姿勢です。支持、接地、反り、サポート配置はスライサーで確認してください。溝やラッチ穴に傷・サポート残りを作らないでください。
  • 試験ブロックは本体と同じ30°の局所回転を入れていません。造形XY方向の影響があるため、必要なら既存の姿勢一致個別片で確認できます。いずれも最終本体で再確認します。
  • 既存試験片には、本体の有効なC0.15入口面取りがありません。 中央の嵌合断面とラッチ穴の条件は対応しますが、挿入開始の感触、外側R1、厚い下面、時計に近い解除アクセスまでは同一ではありません。
  • Hが大きいほど溝の上下壁は薄くなります。最外端の上入口縁の概算は、H340約0.994 / H350約0.944 / H360約0.894 / H370約0.844 mm。P535/P565はH350と同じ約0.944 mmです。これは丸みとC0.15が交わる短い導入縁で、中央の屋根とは別です。全域最小肉厚1.5 mmを保証しません。条件別の確認値は SIX_CASES_FINAL_QA.json を参照してください。
  • JLC3DPやAdventurer 3 + PETGの基本条件は既存の印刷ガイドを使用できますが、CAD公称値だけで保持力を保証できません。

ファイル内容

  • 各IDの .step：編集・寸法確認用。
  • 各IDの .stl：組立座標の本体。
  • 各IDの _print_axisZ.stl：同じ本体の造形候補向き。標準STLと両方を印刷する必要はありません。
  • parameters/<ID>.json：生成寸法と刻印、対応する試験片入力のハッシュ。
  • case_parameters.csv：数値刻印、ID、ファイル名の対応表。
  • SIX_CASES_FINAL_QA.json、build_validation.json：CADとメッシュの検査結果。
  • renders/six_cases_actual_CAD_top.png：実CADから作成した6ケースと刻印の一覧。

このパックはケース6条件です。既存の試験ブロックは変更・再生成していません。寸法ゲージも追加していません。

再生成

Python3.12、CadQuery2.7.0、NumPy2.3.5、DejaVu Sansフォントで検証。表示画像はBlender4.3.2。

pip install -r requirements.txt
python build_variants.py

特定のIDだけ再生成する場合：

python build_variants.py --only H340

生成時は対応する export/ ファイルを上書きします。測定済みの版は保存してください。parameters/*.json は生成記録で、直接編集しても形状には反映されません。実際の6条件は inputs/fixture_conditions.json と生成スクリプト内の照合表で確認しています。
